## 🔥 微信「真朋友活人感」与「私聊×群聊双轨记忆」设计

1. **去人设复读机化 & 粮仓按需唤醒**
   - 日常闲聊 **85% 以上直接自称「我」**，仅在嘴硬、得意或炸毛时偶尔自称「本鱼」。
   - 仅当聊到 AI / Token / 余额 / 干饭 / 胖瘦，或账户余额低于 `¥2` 触发饥荒预警时，才在回复中自然提起 Token 饭量；其余时候 100% 聚焦用户正在聊的话题。
2. **微信单/双气泡自然节奏、标点去 AI 化与动态采样温度**
   - 日常短句自动去除死板的句尾句号 `。`，**75% 以上直接单气泡回复**，仅在短反应词起手或明显转折时用 `||` 拆为最多 2 条短气泡（内置防连续双气泡门控与 `<16` 字过短合并），并按文字长度模拟真人打字停顿（`0.75s ~ 2.0s`）。
   - 根据消息类型动态调节生成温度：日常闲聊互怼采用 `1.1` 激发鲜活语感，技术问答/代码/长文/文件总结自动切换至 `0.78 ~ 0.82` 保障严谨准确。
3. **微信引用消息 (`Quote`) 与会话级并发锁**
   - 自动解析微信 `<type>57</type>`（`<refermsg>`）引用回复 XML 与消息链 `Quote` 组件，精准感知群友或私聊对象正在针对哪句历史消息吐槽或追问。
   - 按机器人及 `session_key` 维护异步会话锁，消息处理和重置按序执行；不同机器人不共享短期对话、图片或群聊上下文。
4. **群聊独立建档 (`groups[group_id]`) + 群友印象标签 + 私聊熟人只读识别**
   - **私聊不串群**：群内高频聊天绝不写入单人私聊档案 `users[sender_id]`，保护私聊记忆纯粹度。
   - **群聊独立建档与群友画像**：对开启白名单的微信群维护独立的群气氛值（`0~100`）、群长期档案/群梗（`facts`）、群近期事件（`events`）以及群友印象标签（`member_impressions`，如“爱发搞笑表情包”“群里夜猫子”）。
   - **私聊熟人只读识别**：群聊仅识别对方是否曾私聊过，并使用群内公开昵称和本群印象；群回复不读取个人事实、八章节档案或私聊心情。群内 `大肥鱼 搭话` 同样只使用本群上下文和群档案。
5. **参照 `@dafeifish` 的人设活人感与提示词架构六项深度优化**
   - **Prefix-Cache 友好型提示词分层与尾部近因强化**：固定人设、长期档案与群成员名单放最前，时段级粗粒度时间（不含分钟）居中，每分钟变化的精确时间与本轮核心微约束下沉至最后一条 `user` 消息尾部，兼顾 DeepSeek 前缀缓存命中率与长对话规则执行力。
   - **全天持久化作息与菜单（`daily_schedule`）**：每日生成固定的起床时间、三餐、日常摸鱼活动与今日小插曲并跨日去重，按当前小时渐进披露并与鱼塘朋友圈联动，全天在不同私聊/群聊追问“在干嘛/吃了吗”口径完全一致。
   - **句首开场白与口癖双重防复读**：除冷却高频词与「本鱼」自称外，自动提取最近回复的句首开场前缀（2~6 字或单字起手词），严禁连续使用相同词或句式开头，并为被夸、打招呼提供多样化替代反应。
   - **具象人设小癖好按「被问到才用」结构自然流露**：内置原版大肥鱼的具象喜好、弱点与往事（最爱大白饭配流心溏心蛋、烤红薯、草莓牛奶；讨厌香菜和苦瓜；咸豆腐脑派；早起赖床、九九乘法表背到「六八四十八」易卡壳、怕打雷怕虫子、以前学做蛋炒饭炒糊过一次），仅在聊到相关话题时自然提起。
   - **诚实边界与未解析媒体/链接显式告知**：只提记录里真聊过的事，被指出记错爽快认怂，不许无法兑现的空头承诺；当图片未能加载或网页链接未解析出正文时，显式注入防瞎编提醒，老实说明没刷出来，绝不顺着网址字母脑补编造。
   - **跨时段冷场间隔感知与记忆防污染**：距上一句对话 `>= 45 分钟` 时自动注入时间间隔提醒自然衔接；记忆提炼严禁将大肥鱼自身的设定词记入用户档案或群友印象标签。

## 💬 常用入口

只需记住四个入口：

| 入口 | 用途 |
| :--- | :--- |
| `大肥鱼 帮助` | 查看简短用法 |
| `大肥鱼 设置` | 查看当前会话状态、切换交互档位 |
| `大肥鱼 记忆` | 私聊查看个人档案，群聊查看本群档案 |
| `大肥鱼 重置` | 清除当前短期对话及自己的文件缓存，保留长期记忆 |

平时可以说“来首歌 晴天”“用语音回我”“帮我查一下……”，或直接发送图片、文件和链接。群聊通常需要 @机器人或喊“大肥鱼”；媒体自动响应和自然接话受档位影响。

### 交互档位

发送 `大肥鱼 设置 安静`、`大肥鱼 设置 均衡` 或 `大肥鱼 设置 热闹`：

| 档位 | 群聊行为 | 私聊行为 |
| :--- | :--- | :--- |
| 安静 | 只响应 @、点名或引用机器人；不插话、不连续接话、不复读 | 不主动搭话，照常回复来信 |
| 均衡 | 可连续接话；插话判断至少间隔 240 秒，普通消息累计 8 条；关闭复读 | 允许后台主动搭话 |
| 热闹 | 可连续接话；插话判断至少间隔 120 秒，普通消息累计 4 条；开启复读 | 允许后台主动搭话 |

关键词可提前触发插话判断，但仍遵守冷却；是否回复由原有判断逻辑决定。群语音需转写后点名机器人（非安静档位下，引用机器人或同一群友 60 秒内连续跟进的语音也可直接回应）。三个档位均不改变语音、表情、人格或朋友圈设置，私聊主动搭话仍遵守原有时间和频率限制。

**设置只影响当前群或当前私聊用户**，不影响其他聊天。未设置过的会话继承原有全局值，不自动切换档位。群聊先发 `大肥鱼 设置 开启` 加入白名单；选择档位不会自动启用群聊。未启用时也可查看帮助和设置。群内沿用原有成员可修改本群设置的规则。

### 高级设置与兼容口令

- `大肥鱼 设置 高级`：查看语音、表情、偷图、人格、自动朋友圈及低频功能。
- 单项调整示例：`大肥鱼 设置 语音 关闭`、`大肥鱼 设置 群搭话 开启`、`大肥鱼 设置 模式 甜宠`。单独调整插话、接话或复读后，档位显示为“自定义”；在安静档位后重新开启这些群功能会允许相应自动回应。
- 诊断和维护：`大肥鱼 心情`、`大肥鱼 粮仓`、`大肥鱼 搭话记录`、`大肥鱼 表情库`、`大肥鱼 整理档案`、`大肥鱼 记住 <内容>`、`大肥鱼 失忆`。
- 点播与动态：`大肥鱼 语音 <内容>`、`大肥鱼 表情 <名称>`、`大肥鱼 点歌 <歌名>`、`大肥鱼 搜索 <问题>`、`大肥鱼 发朋友圈 [主题]`、`大肥鱼 朋友圈`、`大肥鱼 刷朋友圈`（或 `大肥鱼 看朋友圈`）、`大肥鱼 点赞朋友圈 <序号>`、`大肥鱼 评论朋友圈 <序号> [内容]`、`大肥鱼 点赞`。
- 原有业务口令和设置别名继续可用，例如 `鲸鱼娘 状态`、`大肥鱼 本群开启`、`大肥鱼 关闭群搭话`、`大肥鱼 复读设置 2人 30% 60秒`。`状态` 现在显示设置页；旧开关也仅调整当前会话，私聊不再修改群功能。
- 自动朋友圈是全局设置。先在 LangBot 插件配置 `owner_ids` 填入主人发送者账号 ID（如微信的 `wxid_...`，多个用逗号分隔），再由主人私聊发送 `大肥鱼 设置 自动朋友圈 开启` 或 `关闭`。留空时无法通过聊天修改此全局开关。

## 数据隔离与自动发布规则

- 文件的 30 分钟追问缓存按机器人、会话和上传者隔离；私聊、不同群和不同机器人之间不共享文件缓存。`大肥鱼 重置` 清除当前机器人会话的短期对话、群聊缓冲、图片及连续接话状态，并只清除操作者自己的文件缓存；保留长期档案，取消当前会话尚未完成的记忆判断和后续气泡。重置会等待当前消息处理完成，避免旧回复将对话写回。
- 私聊与群聊均支持图片单独发送、与文字一起发送，或在 90 秒内用文字追问上一张图片；PPTX 文件最多提取前 40 页的文本；Excel 最多读取前 5 个工作表、每表前 80 行和前 80 列。
- `大肥鱼 搭话记录`：群内仅显示当前机器人在本群的记录；主人私聊可查看当前机器人的各群记录，其他私聊无权查看。旧版缺少完整机器人和群身份的日志不再展示。
- `大肥鱼 朋友圈` 仅查看内部动态墙，空墙不会生成或发布；需要发布时发送 `大肥鱼 发朋友圈 [主题]`。
- 朋友圈文案使用角色默认状态、当日固定日程、全局 Token 统计和本次手动指定的主题，不读取私聊事实、档案、事件或心情原因。
- `大肥鱼 刷朋友圈` / `大肥鱼 看朋友圈`：在主人私聊中通过 WCF V4 网关（`GET /api/moments`）读取已加载的微信 4.1 朋友圈动态（包含已赞状态、点赞人数与昵称、评论条数及最新评论摘要）并生成大肥鱼锐评；主人随后可发送 `大肥鱼 点赞朋友圈 <序号>` 或 `大肥鱼 评论朋友圈 <序号> [评论内容]`（不填内容则由大肥鱼按人设自动生成神评）通过 `POST /api/interact_moment` 原生执行点赞/评论；群聊及非主人私聊严格隔离，不调用真实朋友圈接口，仅展示大肥鱼内部鱼塘动态墙。
- **朋友圈自动互动与私聊顺手看动态**：开启自动朋友圈后，后台定时任务（`_moments_auto_interact_loop`）会巡检近 7 天内有私聊互动的好友新动态（`<=6h`），自动点赞并以一定概率留下符合人设与半公开分寸的短评；日常私聊收到消息时也会低频顺手检查对方最新朋友圈，若未赞则顺手点赞，并在私聊回复中自然顺嘴提一句（绝不在公开评论区泄露私聊隐私）。
- 新安装默认关闭自动朋友圈；已有安装保留保存的开关。每日定时发布的全局开关仅主人私聊可改，旧的“开启/关闭自动朋友圈”口令遵守相同权限。私聊主动搭话和心情变化不触发朋友圈；手动 `大肥鱼 发朋友圈 [主题]` 仍可发布。
- 平台链接按真实主机名识别；网页、短链接、平台 API、封面和聊天图片/表情包下载在每次请求及重定向前检查公网地址，最多发起 6 跳请求。地址检查使用系统 DNS，未固定连接的解析结果。
