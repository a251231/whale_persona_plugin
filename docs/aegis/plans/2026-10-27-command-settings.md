# 口令精简与会话设置

- 目标：提供帮助、设置、记忆、重置四个主要入口；旧业务口令保留，设置别名归一。
- 架构：新增 `interaction_settings.py` 统一管理设置定义、档位、别名和菜单；监听器负责调用和实际执行，Diana 扩展读取会话有效设置。
- 技术栈：现有 Python / LangBot SDK / unittest，不新增运行时依赖。
- 基线：当前 README、AGENTS.md、用户批准的口令优化方案。
- 兼容：保留现有全局值作为默认；每群/每位私聊用户只保存显式覆盖项。切换档位不改语音、人格或自动朋友圈。
- 验证：先运行失败的入口和作用范围测试，再实现；运行全部回归、语法、Ruff 和差异检查。

## 原子任务

1. 补帮助/设置、三个档位、旧别名和会话隔离的端到端测试，确认失败。
2. 实现会话设置模块：继承旧配置、设置注册表、分层菜单、统一别名和参数校验。
3. 入口在群白名单前处理帮助和设置；移除重复开关处理与长帮助，接入有效设置。
4. 群接话、插话、复读、语音、表情及私聊后台主动搭话都读取对应会话设置。
5. 自动朋友圈保持全局，只有配置的主人在私聊中可以修改；新安装默认关闭，已有安装保留原值。
6. 同步用户文档和执行规范，验证全部旧回归与新行为。

## 边界、退役和风险

- 删除监听器中已由注册表接管的设置口令分支，避免双重命令所有者。
- 帮助只展示四个常用入口及自然表达；状态为设置视图的兼容别名，诊断/低频功能放在高级页。
- 档位不自动加入群白名单；未启用群可查看帮助、设置并使用“设置 开启”。
- 群设置仍沿用原有成员可修改的权限；全局发布权限通过插件配置的主人 ID 列表确定。
- 改动扩展持久化状态，需要验证保存/重载；配置增加主人 ID 字段，修改前备份 manifest。
- 架构检查：需要，核对设置生产者与全部消费者、继承规则、全局发布权限及旧别名兼容。
- 回滚：回退本次源码和 manifest；会话覆盖项不删除原全局值，旧版本会忽略新增字段。
